The funniest honest error message a washing machine could show: too much detergent has turned the drum into foam, and the floor is next. `main.py` (standard library only) writes the one-line entry to `/output/entry.txt`.

## The entry

> ERROR: Too much detergent. I am now 90% foam and 10% machine. The floor is next.

80 characters. The joke comes from the truth of the fault: over-sudsing is a real washing-machine failure — excess detergent fills the drum with foam that the machine cannot drain or spin away, and it leaks out onto the floor. The machine reports it in its own flat voice, without meaning to be funny.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.txt` (override with `OUTPUT_PATH` for local testing).
